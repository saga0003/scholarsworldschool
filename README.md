# Scholars' School Website

Modern Next.js website for Scholars' School, Hassan.

## Deployment

- Framework: Next.js 16 / React 19
- Ready for Vercel and compatible with EdgeOne Pages
- Public school imagery is currently served from `scholarshassan.com`
- The admissions form opens a pre-filled email to `infoscholars@gmail.com`, so enquiries are not written to ephemeral server storage

If database-backed lead capture is required later, connect the form to a persistent database such as Supabase/Postgres.

## Local development

```bash
npm install
npm run dev
```
